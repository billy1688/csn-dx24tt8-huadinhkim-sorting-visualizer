# HƯỚNG DẪN CHẠY CHƯƠNG TRÌNH

## Yêu cầu

- Máy tính có trình duyệt web hiện đại.
- Không cần cài đặt cơ sở dữ liệu hoặc máy chủ.

## Cách chạy

1. Tải hoặc clone repository.
2. Mở thư mục `src`.
3. Mở file `index.html` bằng Chrome, Edge hoặc Firefox.

## Chức năng hiện có

- Nhập mảng thủ công.
- Tạo mảng ngẫu nhiên.
- Điều chỉnh tốc độ mô phỏng.
- Chạy Bubble Sort tự động.
- Tạm dừng và tiếp tục.
- Chạy từng bước.
- Đặt lại mảng.
- Hiển thị mã giả và thống kê.

## Giới hạn dữ liệu

- Mảng có từ 5 đến 30 phần tử.
- Mỗi phần tử là số nguyên từ 1 đến 100.
- Các số được phân cách bằng dấu phẩy, dấu cách hoặc dấu chấm phẩy.
