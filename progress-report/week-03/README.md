# BÁO CÁO TIẾN ĐỘ TUẦN 03

## 1. Thông tin chung

- Học viên: huadinhkim
- Mã lớp: DX24TT8
- Đề tài: Trực quan hóa và so sánh các thuật toán sắp xếp
- Nội dung tuần: Xây dựng giao diện và trực quan hóa Bubble Sort

## 2. Mục tiêu

- Xây dựng giao diện chính của ứng dụng.
- Hiển thị mảng dữ liệu dưới dạng biểu đồ cột.
- Cài đặt thuật toán Bubble Sort.
- Chuyển quá trình sắp xếp thành từng bước trực quan.
- Xây dựng chức năng điều khiển mô phỏng.
- Hiển thị mã giả và thống kê thuật toán.

## 3. Công việc đã thực hiện

- Xây dựng giao diện bằng HTML và CSS.
- Thiết kế giao diện thích ứng với máy tính và điện thoại.
- Xây dựng chức năng nhập mảng thủ công.
- Xây dựng chức năng tạo mảng ngẫu nhiên.
- Hiển thị các phần tử dưới dạng biểu đồ cột.
- Cài đặt thuật toán Bubble Sort bằng JavaScript.
- Tạo danh sách các bước so sánh và hoán đổi.
- Đồng bộ từng bước thuật toán với biểu đồ cột.
- Đánh dấu dòng mã giả đang được thực hiện.
- Xây dựng các chức năng:
  - Bắt đầu.
  - Tạm dừng.
  - Tiếp tục.
  - Chạy từng bước.
  - Đặt lại.
  - Điều chỉnh tốc độ.
- Hiển thị số bước, số lần so sánh, số lần hoán đổi và thời gian mô phỏng.
