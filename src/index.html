Mã giả

Bubble Sort

O(n²)
  1. for i ← 0 to n - 2
  2.   for j ← 0 to n - i - 2
  3.     if A[j] > A[j + 1]
  4.       swap(A[j], A[j + 1])
  5.   mark A[n - i - 1] as sorted
  6. mark A[0] as sorted
