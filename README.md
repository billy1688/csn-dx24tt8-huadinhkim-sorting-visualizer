## Giới thiệu

Đề tài xây dựng ứng dụng trực quan hóa quá trình hoạt động của các thuật
toán sắp xếp. Ứng dụng cho phép người dùng quan sát từng bước so sánh,
hoán đổi và sắp xếp dữ liệu thông qua giao diện đồ họa.

## Mục tiêu

- Mô phỏng trực quan quá trình thực thi thuật toán.
- Hỗ trợ chạy, tạm dừng và chạy từng bước.
- Cho phép điều chỉnh tốc độ mô phỏng.
- Hiển thị số lần so sánh và số lần hoán đổi.
- So sánh thời gian và độ phức tạp của các thuật toán.

## Thuật toán dự kiến

1. Bubble Sort
2. Selection Sort
3. Insertion Sort
4. Merge Sort
5. Quick Sort

## Công nghệ dự kiến

- HTML5
- CSS3
- JavaScript
- Git và GitHub
- Chart.js nếu cần vẽ biểu đồ so sánh

## Cấu trúc repository

- `setup/`: hướng dẫn cài đặt và cấu hình.
- `src/`: mã nguồn chương trình.
- `progress-report/`: báo cáo tiến độ hằng tuần.
- `others/doc/`: tài liệu Word.
- `others/pdf/`: tài liệu PDF.
- `others/html/`: tài liệu dạng web.
- `others/abs/`: các tài liệu khác theo yêu cầu.
- `soft/`: phần mềm liên quan nếu có.

## Cách chạy chương trình

1. Tải hoặc clone repository.
2. Mở thư mục `src`.
3. Mở file `index.html` bằng trình duyệt.
